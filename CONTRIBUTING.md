# CONTRIBUTING

Thank you for your interest in contributing to **Atropisomers**! We welcome contributions from the community and aim to foster a collaborative and transparent development process.

## How to contribute

### Reporting issues

If you encounter a bug, unexpected behavior, or documentation inconsistency:

1. **Search first** to see if your issue has already been reported.
2. If not found, [open a new issue](https://github.com/AstraZeneca/atropisomers_workflow/issues/new) and provide:
   - A clear and descriptive title.
   - Steps to reproduce the problem, including chemical parameters.
   - Relevant error messages, logs or screenshots.
   - Environment info (e.g. python version, platform, etc).

### Suggesting enhancements

We welcome ideas to improve features, usability or functionality.

- Describe the proposed enhancement clearly.
- Explain the use case or motivation.
- Optionally suggest a possible implementation.

If you want to contribute code or documentation please contact [elliot.farrar@astrazeneca.com](mailto:elliot.farrar@astrazeneca.com).
